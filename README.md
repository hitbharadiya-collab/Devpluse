# DevPulse - Enterprise DevSecOps Control Plane

Full-stack Zero-Trust DevOps & DevSecOps platform built with React 19, TypeScript, Tailwind CSS v4, Express 5, and PostgreSQL.

## Features
- Google OAuth 2.0 SSO, Brevo 6-Digit Email OTP, Authenticator TOTP 2FA & WebAuthn Hardware Passkeys
- Brute-Force Rate Limiting, Helmet Security Headers & PostgreSQL Persistent Sessions
- Live GitHub Repository Sync (/api/github/repos), CI/CD Pipeline Tracking & CSV Compliance Reports

## Run Locally
npm install && npm run dev
